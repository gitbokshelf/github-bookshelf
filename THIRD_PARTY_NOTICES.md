# Créditos e componentes de terceiros

GitHub Bookshelf é um projeto de Thiago Ebias. A identidade visual do portal, capas editoriais, composição da biblioteca, curadoria, filtros e persistência foram desenvolvidos para este projeto. Nomes e marcas dos projetos listados pertencem aos respectivos titulares.

## Componentes recebidos via 21st.dev

Os componentes abaixo foram fornecidos como código pelo autor do projeto para integração. Os exemplos de demonstração anexados não fazem parte do portal; o catálogo usa seus próprios dados e sua própria composição visual.

- Arquivo: `frontend/src/components/ui/glass-folder-cards.tsx`.
