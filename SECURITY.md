# Política de segurança

A versão suportada é o código atual de `main`. Consulte a [engenharia de segurança](security/README.md) para escopo, controles e riscos conhecidos.

## Relatar vulnerabilidade

Use [relato privado de vulnerabilidade](https://github.com/gitbokshelf/github-bookshelf/security/advisories/new). O recurso está habilitado no repositório. Como alternativa, contate `githubbokshelf@outlook.com`, sem enviar senhas, tokens, sessões, dumps ou dados de outras pessoas.

Informe ambiente/versão, impacto, passos mínimos com dados fictícios e evidência sanitizada. Não publique detalhes exploráveis em issue pública antes da correção coordenada.

Testes devem respeitar o alvo autorizado. Não realizar força bruta, carga em produção, acesso a dados de terceiros ou persistência no ambiente. O projeto não oferece programa de recompensa nem promessa de atendimento 24 horas. O responsável fará a triagem e combinará prazo conforme impacto e disponibilidade.
