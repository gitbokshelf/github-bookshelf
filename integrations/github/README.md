# GitHub

Repositório público exclusivo: [gitbokshelf/github-bookshelf](https://github.com/gitbokshelf/github-bookshelf).

Criado pelo Safari em 17/10/2026 na conta `gitbokshelf`. O envio do código revisado ainda depende da autenticação dessa conta na ferramenta de publicação. O histórico local de `thiagoebias/github-bookshelf` e a autoria de Thiago Ebias serão preservados.

A CI em `.github/workflows/ci.yml` valida testes, TypeScript e orçamento de build em pushes e pull requests. A hospedagem principal prevista é a Vercel; o novo repositório não depende de GitHub Pages.

Credenciais locais usam `*.local.*` ou `private/`, ignorados pelo Git. A autenticação da CLI é gerenciada pelo próprio `gh`; nenhum token deve ser copiado para esta pasta. O vínculo da conta Gmail informado pelo proprietário permanece no cadastro privado da integração.
