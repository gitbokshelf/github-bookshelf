# E-mail do projeto

Pasta destinada à integração futura do endereço exclusivo informado pelo proprietário. Nenhum acesso à caixa postal, envio, coleta de senha ou configuração SMTP foi feito.

Dados de conexão locais devem usar `*.local.*` ou `private/`, ambos ignorados pelo Git. Não registrar senhas nesta documentação pública.

Ter uma caixa postal não configura automaticamente o envio transacional do Supabase. A escolha e a validação de um serviço de entrega com o domínio do produto permanecem pendentes.
